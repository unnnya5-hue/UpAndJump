# 無限昇進 — 企画資料・操作モック

iPhone向けエンドレス上昇ゲーム「無限昇進」の初期企画です。

## ファイル

- `REQUIREMENTS.md` — MVPを中心とした要件定義書
- `ASSET_GUIDE.md` — 実装用イラスト一覧・利用仕様・生成プロンプト
- `SOUND_GUIDE.md` — BGM・効果音の選定結果と実装仕様
- `audio/` — 原音、AAC試聴版、ライセンス記録
- `mock/` — ブラウザで操作できるゲームモック

## モックの起動

このディレクトリで次を実行します。

```bash
python3 -m http.server 8080
```

ブラウザで <http://localhost:8080/mock/> を開いてください。

選定したBGM・効果音は <http://localhost:8080/audio/preview.html> で試聴できます。

### 操作

- iPhone / タッチ端末：画面上を左右にスワイプして移動
- PC：左右キーまたは `A` / `D`
- 右上のボタン：ポーズ / 再開

モックはゲームループ、難易度上昇、アイテム取得と効果、衝突、スコア、ベストスコア、リトライまでを確認するためのもので、最終的な数値や物理挙動を確定するものではありません。
